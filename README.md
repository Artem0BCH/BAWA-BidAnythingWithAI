# BAWA ISN'T A REAL BIDDING PLATFROM AND IS A DEMO WITHOUT AN ABILITY TO USE REAL MONEY.. YET

## BAWA is a bidding platfrom for literally anything, well, as long as it's legal (don't factcheck) and it has an AI integration! Which is your own, personal one that you can plug in with an API key!

BAWA is made with JS, React and MySql.
BAWA is open-source, but the work must ALWAYS be used with permission.

## How BAWA works:

BAWA works based on having users, any user can be a buyer and a bid maker on the same account.

in BAWA you can use your own AI API key to have the AI help you in a more seamless fashion, with really anything!

We also have ideas for some neat features, I am currently writing this before we have begun the project but this should feel almost like a minigame.
